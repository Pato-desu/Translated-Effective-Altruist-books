## 制作方式与质量

每本书先被切成段落大小的批次（链接、脚注和图片以占位符保留），由 AI 模型翻译，再自动检查：有无遗漏、是否残留英文、链接是否完好、关键术语是否一致。未通过的批次会重译，最后重新生成 EPUB。最早的两本西班牙语译本用 Calibre 和 Gemini 制作；此后的全部由 Claude 驱动的自动流程完成。

**请注意：**这些书都没有经过人工校对。由 PDF 转来的书可能留有提取残留（零散的 `[^` 标记、异常换行）。质量与审计报告见 [`reports/`](reports/)。

- Eliezer Yudkowsky（MIRI）的 *Rationality: From AI to Zombies* 采用 CC BY-NC-SA 3.0 许可。其西班牙语译本是同一许可下的衍生作品：署名、非商业、相同方式共享。
- 其余书籍均为已出版作品，权利归作者和出版社所有。这里仅作为非商业的无障碍阅读尝试分享。如权利人提出异议，请提交 Issue，文件将被移除。
- [`sources.md`](sources.md) 记录了每本书的来源及已知的许可情况。

## 开发者

命令见[英文 README](README.md#for-developers)。Python 3.11；`pip install -r requirements.txt`；在本文件夹内运行。无需 Calibre。

**添加新书：**把文件（EPUB、含文本的 PDF、Markdown、HTML 或纯文本）放入 `inbox/`，并在 `QUEUE.md` 中加一行。添加后，请在三个 README 的表格中各加一行；缺少时 `python -m pytest` 会失败。
